# URL Shortener

A small URL-shortening application with authentication, role-based permissions, URL management, pagination, and an editable About page.

## Technologies

- ASP.NET Core MVC and .NET 10
- Entity Framework Core and SQL Server
- Angular 22
- Bootstrap
- xUnit

## Development Note

I had never worked with Angular before creating this project, so the Angular part was created with the help of AI agent. Everything else was designed and implemented through my own knowledge and effort.
